Integration library

Declarative packs

Installed packs are inert until a passport grant exists. Review permissions, install declarative packs, grant exact capabilities, and disable grants locally.

Community packs

Extensions

Install signed third-party manifests, then issue per-passport grants. Installation alone never grants tool access — an explicit grant must exist before any agent can dispatch through the extension.

Trusted signing keys

Manifests are verified against this keyring. The dev bypass CORECRUXD_EXTENSIONS_ALLOW_UNSIGNED=1 lets unsigned manifests install for local testing only.

Install manifest

Paste a signed integration manifest as JSON. Required fields: id, version, publisher, kind, signature. For external-tool packs, also external_tool_endpoint and tools[].
