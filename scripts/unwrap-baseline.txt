# Non-test unwrap()/expect() baseline per crate.
#
# 2026-07-29 RE-BASELINED. The previous counts measured test code, not
# production code, and the gate had a blind spot that hid real production
# sites. Three defects, all fixed in scripts/unwrap-ratchet.sh in this change:
#
#   1. src/http/tests.rs (20,599 lines, 590 sites) and src/metrics.rs (2,429
#      lines, 240 sites) were counted. tests.rs is #[cfg(test)] via an
#      out-of-file #[path] mod decl, so it carries no in-file marker for the
#      scan to key on; metrics.rs is the allowlisted Prometheus register!()
#      surface. ~95% of the old corecruxd baseline of 857 was these two files,
#      which is why every increment since 2026-07-12 was test code.
#   2. The scan set intest=1 on the FIRST #[cfg(test)] in a file and never
#      reset, exempting everything after it. This was not theoretical:
#      corecrux-storage/src/lib.rs hid 6 production try_into().unwrap() sites
#      in the binary frame decoder behind a #[cfg(test)] at line 1345, and
#      corecruxd/src/main.rs hid the SIGTERM-handler expect() at line 2291.
#      The scan now tracks brace depth so a #[cfg(test)] exempts only its item.
#   3. Full-line // comments mentioning .unwrap() were counted as sites.
#
# Net effect: corecruxd 857 -> 50, corecrux-receipts 85 -> 0 (all 85 were in
# src/tests.rs; receipts production code has zero unwrap/expect), and
# corecrux-storage / crux-observe went UP as previously-hidden production
# sites became visible. Per-PR increment history before this date is in git
# history; it described test-code growth and no longer applies.
#
# Method: count lines containing .unwrap()/.expect( in crates/<crate>/**/*.rs,
#   excluding */tests/* paths, files named tests.rs or metrics.rs, full-line
#   comments, and items under an inline #[cfg(test)] (brace-scoped).
# Consumer: scripts/unwrap-ratchet.sh. CI fails if any crate exceeds its
#   baseline; lowering a count updates this file in the same PR.
# Self-test: scripts/unwrap-ratchet.sh --self-test (covers the mid-file
#   #[cfg(test)] regression from defect 2 above).
#
# 2026-07-31: corecruxd 47 -> 45, corecrux-secrets 0 -> 2. Not new debt — the
# corecruxd crate-split moved encrypted_secrets.rs into corecrux-secrets, and
# its two infallible expect() sites (fixed-length XNonce conversion; an encrypt
# that only fails on programmer error) moved with it. Whole-tree total is
